# Interplanet travel energy calculation: frontend

Фронтенд на React + TypeScript (Vite, React-Bootstrap, react-router-dom) для просмотра услуг (рейсов между планетами). Интерфейс рассчитан на вертикальный экран телефона: в браузере это узкая колонка 430 px по центру. Приложение работает для гостя, данные берутся только из mock-коллекции (`src/modules/mock.ts`), бэкенд не подключён. Redux и React Context не используются.

## Запуск

```bash
npm install
npm run dev
```

Приложение доступно на http://localhost:3000/ (адрес `/` перенаправляет на ленту).

## Адреса страниц

| Адрес | Страница |
|---|---|
| `/` | перенаправление на `/feed` |
| `/feed` | Лента (первая услуга) |
| `/feed/:id` | Лента, открытая на услуге с данным id |
| `/tiles` | Плитка |
| `/create` | Создание (открывается только по адресу, из панели недоступна) |
| любой другой | перенаправление на `/feed` |

## Навигационная панель

Закреплена внизу экрана на всех страницах (React-Bootstrap `Navbar`), 4 пункта:

| Пункт | Иконка | Состояние | Переход |
|---|---|---|---|
| Лента | дом | доступен | `/feed` |
| Добавление | плюс | недоступен (затемнён, не нажимается); страница открывается только по адресу `/create` | - |
| Плитка | плитки | доступен | `/tiles` |
| Вход | человек | недоступен (затемнён, не нажимается) | - |

Активный пункт подсвечивается белым по текущему адресу. Когда открыта страница `/create`, подсвечивается и недоступный пункт «Добавление».

## Страницы

### Лента (`/feed`, `/feed/:id`)
Одна услуга на весь экран: видео фоном (автозапуск, без звука, по кругу). Если у услуги нет видео, играет видео по умолчанию. Поверх видео: название, число лайков, описание, расстояние и период сближения. Без `id` в адресе, а также при неверном `id`, показывается первая услуга.

| Элемент | Действие |
|---|---|
| Кнопка со стрелкой | переход к следующей услуге по возрастанию id; после последней открывается первая |
| Счётчик с сердцем | число лайков (только просмотр, гость лайкать не может) |
| «Узнать больше» / «Свернуть» | раскрывает и сворачивает описание (по умолчанию видны две строки) |

### Плитка (`/tiles`)
Опубликованные услуги карточками в две колонки. В карточке: изображение (по умолчанию, если пусто), название, расстояние, период сближения, число лайков. Клик по карточке открывает ленту на этой услуге.

Фильтр сверху. Список обновляется сразу при изменении любого поля:

| Элемент | Тип | Что делает |
|---|---|---|
| Мин. расстояние | ползунок 1-500000 | нижняя граница расстояния, св. лет (не выше верхней) |
| Макс. расстояние | ползунок 1-500000 | верхняя граница расстояния, св. лет (не ниже нижней) |
| Кнопка-воронка | кнопка | раскрывает и скрывает панель с остальными полями фильтра |
| Название | текст | оставляет услуги, в названии которых есть введённая подстрока (без учёта регистра) |
| Опубликовано с | дата | оставляет услуги, опубликованные не раньше выбранной даты |
| Сортировка | выпадающий список | сначала старые / сначала новые, названия А-Я / Я-А, сначала ближайшие / сначала дальнейшие |
| Сбросить фильтр | кнопка | возвращает все значения по умолчанию |

Если ничего не подошло, выводится сообщение «Ничего не найдено».

## Изображение и видео по умолчанию
Если у услуги пустое поле `photo_url`, на плитке и в других местах используется `public/default/photo.png`. Если пустое поле `video_url`, в ленте играет `public/default/video.mp4`. Те же файлы показываются в превью на странице «Создание», пока пользователь не выбрал свой файл. Если ссылка на фото задана, но не открывается, подставляется фото по умолчанию.

## Данные
Услуги хранятся в `src/modules/mock.ts` в формате ответа бэкенда:

| Поле | Описание |
|---|---|
| id | идентификатор (используется в адресе ленты) |
| name | название |
| description | описание |
| status | `draft` или `published` (гость видит только опубликованные) |
| photo_url, video_url | пути к фото и видео (пусто: подставляются файлы по умолчанию) |
| distance | расстояние, св. лет |
| period | период сближения, лет |
| creation_time, forming_time | дата создания и дата публикации |
| creator_id | создатель |
| like_count | число лайков |
